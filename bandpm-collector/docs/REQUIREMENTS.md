# BandPM Collector 要件定義書

## 1. 目的

アマチュア吹奏楽団の公開Webサイトから基本情報を抽出し、営業・市場調査・顧客管理に使える形式へ整理する。

## 2. MVP完成条件

1. 複数URLを入力できる
2. ページ取得の成功・失敗を確認できる
3. 団体情報を表形式で確認できる
4. 抽出結果を手動修正できる
5. CSVとして保存できる
6. READMEにセットアップ手順がある

## 3. 取得項目

- 団体名
- 都道府県
- 市区町村
- 公式サイト
- 問い合わせURL
- 公開メールアドレス
- 団員募集情報
- 練習情報
- 演奏会情報
- 情報元URL
- 取得日時
- 信頼度
- 備考

## 4. MVP対象外

- 検索エンジン結果の自動取得
- 全国一括収集
- SNSログイン
- メール自動送信
- 定期監視
- クラウド公開
- 複数ユーザー対応
